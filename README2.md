# 천안시 청년정책 인터랙티브 웹 프레젠테이션

첨부된 10장 PPT를 원본 디자인 그대로 보여주는 서버리스 정적 웹 프레젠테이션입니다.

## 구성

- `index.html`: 홈페이지 (GitHub Pages 시작 파일)
- `styles.css`: 반응형 디자인 및 애니메이션
- `script.js`: 탐색, 상세 정보, 키보드, 터치 등 상호작용
- `assets/slide-1.png` ~ `slide-10.png`: 원본 PPT에서 렌더링한 슬라이드 (원본 내용과 시각 요소 보존)

## GitHub Pages 배포

1. 새 GitHub 저장소를 만들거나 기존 저장소를 엽니다.
2. `index.html`, `styles.css`, `script.js`, `assets` 폴더를 저장소 **루트**에 업로드합니다. (ZIP 자체만 업로드하면 실행되지 않습니다.)
3. 저장소 **Settings > Pages > Build and deployment** 에서 **Deploy from a branch**를 선택합니다.
4. Branch를 **main**, Folder를 **/(root)**로 선택하고 저장합니다.
5. 게시 후 `https://<사용자명>.github.io/<저장소명>/`에서 볼 수 있습니다.

서버 또는 데이터베이스가 필요 없으며, 외부 JS/CSS 라이브러리도 사용하지 않습니다. 자산 경로는 상대 경로이므로 프로젝트 페이지에서도 작동합니다.

## 기능

- 전체 목차 및 위쪽 섹션 이동
- 이전/다음, 진행 표시, 슬라이드 점 메뉴
- 좌/우 화살표, Page Up/Down, Space, G(목차), F(전체화면)
- 화면에서 좌/우 스와이프, PC의 마우스 휠 전환
- 주요 정책 카드 선택 → 상세 내용 팝업
- 접근성 대체 텍스트, 반응형 레이아웃, 모션 감소 설정 지원

## 정확도 안내

원본 디자인/도표/주석의 시각적 손실을 막기 위해 PPT의 각 장을 PNG로 렌더링하여 사용했습니다. 텍스트는 상세 내용 팝업에도 제공하지만, 슬라이드 이미지 내부의 글자는 별도 DOM 요소로 편집할 수 없습니다. 정책 통계 미확인·정책 비전 비공식 표기 등 원본 주의문구를 그대로 유지했습니다.
